# Appform2

This repository contains the `loan-portal` Next.js application in `/home/runner/work/Appform2/Appform2/loan-portal`.

## Working from the repository root

Root-level npm scripts proxy to the nested app so the project can be built and started from the repository root:

```bash
npm install
npm run build
npm run start
```

## Vercel deployment

When creating the Vercel project, set the **Root Directory** to `loan-portal` and configure the environment variables documented in `/home/runner/work/Appform2/Appform2/loan-portal/.env.example`.
